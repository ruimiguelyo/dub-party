# Dub Party

**▶ Play: https://ruimiguelyo.github.io/dub-party/**

A free dubbing party game you play in the browser with your friends. Works with the "Dub Mode" packs from GameBanana.

## How to play (2 minutes)

1. Download a pack from [GameBanana · Dub Mode](https://gamebanana.com/mods/cats/44064) (.zip, .rar or .7z).
2. Open the link above and drop the pack in (**Escolher pacote**).
3. Click **Criar sala** (create room) and send the code to your friends.
4. Your friends open the same link, type the code and get the pack automatically. They don't need to download it.
5. Everyone picks a character and records their lines, with voice effects (robot, monster, radio…).
6. When everyone is done, the dub plays for the whole room at the same time, with live reactions 😂🔥💀.

No account, no download, nothing to set up. Use headphones.

## Install it as an app (optional)

Chrome / Edge: click **⬇ Instalar** at the top of the page, or the install icon in the address bar.
Firefox-based browsers: use the browser menu. Phone: "Add to home screen".
Once installed it opens in its own window and works offline for solo play.

## Your own copy (optional)

Want your own link? With a GitHub account:
1. Click **Fork** at the top of this page.
2. In your fork: **Settings → Pages → Branch: `main` → Save**.
3. A minute later it's live at `https://<your-username>.github.io/dub-party/`.

The whole game is a single `index.html`. Any static host works.

## Privacy

There is no server and no account. Packs and recordings stay in your browser. In a room they go straight from player to player (peer-to-peer), so only share room codes with people you know.

Packs belong to their authors. Dub Party doesn't host any video.
